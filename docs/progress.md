## 实际验收

- `npm run verify`：lint、Prettier、TypeScript、模块边界及 30 个文件共 314 项测试通过。
- 真实 Docker 酒馆 1.19.0 / 1.13.2；Edge 154.0.4258.37 / Firefox 153.0。三模式暂停继续均通过；主要操作、故障隔离、导出恢复详情见 [浏览器验收](host-smoke.md)。
- 旧代码 `c333ca2` 在独立浏览器 context 加载，导入新版本已经生成的 3 块完整任务并重新导出，章节和世界书逐字段相同。没有用旧代码覆盖真实用户数据库。
- 100 MB 无分隔符文本切块保持全部字符与唯一章节 ID；修复全前缀反复搜索后约 630 ms。真实 Edge 上传与渲染 1 MB / 10 MB 分别约 272 / 2138 ms。

## 保留的兼容边界

- `txtToWorldbook/services` 仍容纳 UI 适配与兼容装配；纯业务命令、条目、格式及切块已迁入 `src/worldbook`。没有为目录统一而搬动所有历史 UI 代码。
- 旧公开 API 的可变对象返回值继续兼容；第三方脚本直接修改对象不属于命令事务保护范围。新业务应调用命令入口。
- Web Locks 要求 localhost 或 HTTPS，缺少能力时明确阻止任务启动。运行锁覆盖生成、编辑、文件操作与任务导入；设置面板可继续编辑，当前运行使用启动时的配置快照。
- 人工修改/删除在章节重 Roll 后保留；明确执行单条目重 Roll 时，该条目的新结果成为新的覆盖值。
- 凭据从普通设置中分离，但仍是浏览器本地明文；旧本地设置自动迁移。任务文件内凭据不自动覆盖当前凭据，导入旧任务后按需重新填写。
- checkJs 当前覆盖恢复记录、写入锁、编辑覆盖、切块四个模块，不代表全部旧代码已获得静态类型保证。
- 模型响应为固定 HTTP/SSE 样本，未调用付费模型；真实供应商鉴权、代理 CORS 和模型质量不在这次结论内。移动端验证为桌面浏览器 390×844 视口，不声称实机验证。
