## 兼容契约

- `tests/fixtures/public-api.json` 固定全部 45 个公开方法/别名；`tests/app/publicApi.test.js` 保护列表、旧别名、getter 的可变引用与历史调用。
- `tests/fixtures/legacy.js` 只包含合成小说、任务和世界书，不含用户正文或真实密钥。任务格式为历史 `2.9.0`，包含成功/待处理块、分卷、配置；ST entries 同时覆盖数组和对象，包含禁用、顺序、递归及未知字段。
- 根入口、`window.TxtToWorldbook`、`nagDebug` 和现有 DOM id 在此批次保持不变。
